# Activity 4 — User Journey Map
Scenario: Ordering food on Swiggy

## Steps:

1️⃣ Open the Swiggy app

2️⃣ Location confirmation

3️⃣ Browse restaurants

4️⃣ Apply filters (cuisine, ratings, price)

5️⃣ Select a restaurant

6️⃣ Browse menu

7️⃣ Add items to cart

8️⃣ Checkout → address confirmation

9️⃣ Apply coupon / change payment method

🔟 Payment completed

1️⃣1️⃣ Live order tracking

1️⃣2️⃣ Food delivered

## 😊 Happy moments
- Clear food photos & ratings
- Live order tracking helps give an ETA
- Payment options are flexible

## 😣 Frustrating moments
- Long load times when browsing restaurants
- Minimum order values and hidden delivery fees
- Coupons often not applicable (confusing validation)
