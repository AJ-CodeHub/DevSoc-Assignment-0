# 🏓 Pong Game (Game Dev Vertical)

This is my submission for **DevSoc BITS Goa Assignment 0** under the **Game Development** vertical.

## 🎮 About the Game
A modern remake of the classic **Pong** built using **Python** and **Pygame**.

- Two-player local multiplayer
  - **W / S** → Move left paddle (Player 1)
  - **↑ / ↓** → Move right paddle (Player 2)
- Dynamic ball physics and score tracking
- Custom sprites for paddles, ball, and background
- Background music and hit sound effects
